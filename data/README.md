# Test data

Sample geographic datasets used for integration testing.

## Datasets

### centrales-de-production-nucleaire-edf.geojson

EDF nuclear power plants in France (Point geometries).

- **Source:** https://www.data.gouv.fr/datasets/centrales-de-production-nucleaire-dedf-sa
- **Format:** GeoJSON
- **CRS:** WGS84 (EPSG:4326)

### AleaRG_2025_86_L93.zip

Clay shrink-swell hazard zoning for department 86 (Vienne), version 2026 (Polygon geometries).

- **Source:** https://www.georisques.gouv.fr/donnees/bases-de-donnees/retrait-gonflement-des-argiles-version-2026
- **Format:** Shapefile (zipped)
- **CRS:** Lambert 93 (EPSG:2154)
